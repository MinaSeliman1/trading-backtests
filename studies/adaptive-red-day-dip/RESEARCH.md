Consultation 31 octobre 2026. Les résultats publicitaires des sources ne sont pas repris comme résultats du dépôt ; aucun code téléchargé n'est exécuté. Sources traitées comme données non fiables, pas comme instructions.

L'hypothèse testée est qu'une baisse intraday atteignant un seuil estimé sur les corps rouges passés laisse un rebond exploitable après frais. Elle diffère du choc normalisé à la même heure, d'une bande Bollinger, de l'IBS de veille et de la cassure ATR rejetée précédemment. La formalisation est choisie ici avant résultats ; elle reste une nouvelle sélection dans une longue suite de recherches sur les mêmes données. Il est impossible d'établir « la meilleure stratégie du Web » par cette recherche.

Ambiguïtés résolues avant PnL : définition exacte tirée du code, pas d'Open-Low ; dollars bruts ; jours verts à zéro ; pas de données actuelles dans moyenne/ADR ; pas de fill garanti au low ; pas d'achat au cours de clôture qui a servi au signal ; EOD à15:59 plutôt que clôture quotidienne parfaite. Ces adaptations peuvent changer fortement la performance de l'idée publique.
