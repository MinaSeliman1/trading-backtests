# Recherche large et choix — 31 octobre 2026

Nouvelle famille : prix relatifs des deux ETF, et non RSI/IBS, calendrier ou nouvelle variante ORB. La recherche ne certifie pas une meilleure stratégie universelle. Les sources motivent un test, pas un résultat local. Aucun code externe exécuté ou copié.

- [clockkaya, README et code](https://github.com/clockkaya/kalman-filter) : source primaireSPY/QQQ lue, Kalman sur15observations de niveaux, entrée1sigma, stop2, hedge dynamique ; code de terminal, pas backtest certifié. Notre règle est différente : retours RTH normalisés, référence passée au même créneau, dollars équilibrés, seuil2/stop3, une paire/EOD. Ni Kalman ni promesse production-ready repris.
- [Pratikbhanuse, code Quantopian](https://github.com/Pratikbhanuse/SPY_QQQ-pair-trading/blob/master/SPY_QQQ_pairtrading_quantopian) : source primaire lue ; écart de niveaux30jours, poids+/−50%, observation une heure avant close. Le code comporte `zscore<1` sur la branche long et un nom `sorting_spread` différent de `shorting_spread` ; ses règles ne sont pas reprises aveuglément. Pas de preuve financière importée.
- [ExeQution Analytics, PDF11pages](https://exequtionanalytics.com/wp-content/uploads/2024/12/Pairs-Trading-An-Intraday-Investigation.pdf) : expérience intraday sur actions japonaises avec sélection de paires, z-scores et clôtureEOD ; échantillon court et étude de sensibilité aux coûts insuffisante selon leurs limites. Famille pertinente, univers/méthode distincts ; ni leurs chiffres ni une cointégration de nos ETF ne sont revendiqués.
- [Leung/Li,2015, résumé primaire](https://arxiv.org/abs/1411.5062) : formalise entrée/sortie avec coûts et stop pour un spread supposé mean-reverting ; ne prouve pas que QQQ/SPY l'est. Notre choix du seuil est fixé avant PnL.
- [Martin/Schöneborn,2011, résumé primaire](https://arxiv.org/abs/1103.4934) : les coûts imposent une zone d'inaction ; motivation d'une sensibilité cost_gate, pas reproduction de leur solution optimale.
- [Ross, prépublication2026](https://zenodo.org/records/22059837) : auteur souligne la difficulté de concilier spread négociable, tests de cointégration et coûts sur ETF liquides. Résumé consulté, pas réplication. Nos retours intraday ancrés ne suppriment pas le risque de faux effet ou de régime.
- [Simonson, High-Frequency ETF Pairs Trading](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3092739) : résumé trouvé, page bloquée403 ; aucune règle détaillée prétendument lue.
- [Forum mean-reversion ES/NQ2026](https://www.reddit.com/r/algotrading/comments/1sm6y5g/backtested_intraday_mean_reversion/) : stratégies long-only séparées, pas un spread ni règles intégrales ; chiffres non audités, concentration/régime discutés. Non retenu comme recette.
- [SPY intraday momentum, code GitHub](https://github.com/nyyyaomi/intraday-momentum-research) : famille déjà couverte par Noise Area ; repéré par recherche seulement, pas exécuté ni audit complet.
- [Bollinger, bibliothèque AlphaCharts](https://getalphacharts.com/backtest/bollinger-bands-strategy) : résultats daily et modèles différents, pas une preuve intraday. Variantes de momentum/calendrier déjà nombreuses ici ; n'ajouter qu'un réglage ne crée pas un échantillon aveugle.

Le coût d'une paire comprend quatre ordres et un short, même si le marché paraît couvert. Le spread dollar-neutre n'est pas bêta-neutre et les fills simultanés restent une hypothèse. Rapport de portefeuille et contributions par jambe distingueront ces unités au lieu de produire deux rendements ETF indépendants trompeurs.
